# Lesson content

Lesson JSON lives here, versioned with the app (per DEVQUEST_PLAN.md §5:
content authored as JSON in the repo, validated by a schema, rendered by one
lesson player).

`lessons/sample-lesson.json` is a shape preview only. Milestone 2 delivers:

- the full content schema (tracks → units → lessons → exercises)
- a validator for all 6 exercise types
- the complete Track 1 curriculum (~30 lessons)
- an internal previewer
